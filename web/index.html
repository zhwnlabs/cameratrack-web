INFO

TENTANG PROYEK

01

APA ITU CAMERA TRACKING?

Camera Tracking adalah pelacakan gerakan tangan lewat webcam. Posisi 21 titik pada tiap tangan dikenali secara real-time, lalu dipakai sebagai pengontrol: tanpa mouse, tanpa sentuhan.

Proyek ini adalah versi web dari RetroLens (Python + OpenCV), dikemas ulang menjadi playground pixel yang bisa langsung dicoba.

02

BAGAIMANA CARA KERJANYA?

  1. Kamera menangkap frame dan dicerminkan seperti kaca.
  2. Model Hand Landmarker mencari hingga 2 tangan.
  3. Ujung jari menjadi sudut portal.
  4. Filter dipasang hanya di dalam area portal.
  5. Gestur pinch dan kepalan mengubah filter dan mode.

03

TEKNOLOGI

  • MediaPipe Hand Landmarker (model hand_landmarker.task yang sama dengan versi Python)
  • Canvas 2D untuk filter piksel dan render portal
  • HTML, CSS, JavaScript murni (ES modules), tanpa backend
  • GitHub Pages + GitHub Actions untuk hosting statis

04

CARA MENCOBANYA

  1. Buka Playground, tekan MULAI KAMERA.
  2. Izinkan akses kamera di browser.
  3. Mundur hingga kedua tanganmu terlihat penuh.
  4. Bentangkan tangan, lalu coba pinch dan kepalan!

PRIVASI: seluruh proses kamera berjalan di perangkatmu. Tidak ada gambar atau rekaman yang dikirim ke server. Kamera otomatis dimatikan saat kamu menekan berhenti, meninggalkan playground, atau menutup tab.
